答题卡 · 视觉模型识别

直接看图识别涂卡 → 按题号核对 → 导出答案。支持分区答题卡，无 OCR 依赖。

从 GitHub 安装粉笔答题卡助手由 Tampermonkey 打开脚本安装界面

1. 连接视觉模型

密钥不写入文件或浏览器存储，经本机服务调用模型。关闭页面后重新填写。

发送程序生成的小色块图测试，可能产生少量 API 费用，不发送答题卡。

查看 / 调整识别提示词

程序会自动追加输出协议和本次题号范围：仅返回题号、选项、状态及必要疑点的 JSON，不返回解释段落。请保留空题和疑问题，避免答案错位。

2. 选择照片与题号

选择照片后，可拖框裁剪答题区
建议裁去姓名、准考证区，只保留完整答题区及印刷题号。

局部图不会增加源照片细节，但可以帮助模型定位小字与涂点。会增加图片输入量和费用；不清晰的题仍需核对。

点击识别会把当前选区图片发送给上方指定的模型服务，按该服务的 API 计费。请先检查服务商地址和裁剪范围。

3. 核对答案

A–E 为模型读到的涂项；— 为未涂；? 为看不清、多涂或模型遗漏。黄色格子必须核对。模型也可能误判已识别项，请对照原图检查。
尚未识别。也可以先填写接口，再用第 1–4 题检查效果。

导出保留原始题号。题目未涂时不会向前挤位。当前工具尚未自动点击粉笔网页选项。

识别期间无需保持模型网页打开。此程序通过 API 调用模型；聊天产品的订阅和 API 额度以服务商说明为准。
